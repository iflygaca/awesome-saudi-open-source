## E-Invoicing & ZATCA

ZATCA (Zakat, Tax and Customs Authority) e-invoicing is a compliance requirement in Saudi Arabia. These projects provide implementations, SDKs, and tools for Fatoora QR code generation and Phase 2 compliance.

|---------|-------|----------|-------------|

| [wes4m/zatca-xml-js](https://github.com/wes4m/zatca-xml-js) | ⭐ 90 | TypeScript | An implementation of Saudi Arabia ZATCA's E-Invoicing requirements, processes, and standards in TypeScript |

## Guidelines for Contributing

Want to add your project or suggest improvements?

1. **For new projects:** Ensure the project:
   - Is open-source (MIT, Apache 2.0, GPL, or similar)
   - Has been developed or maintained primarily by Saudi developers/organizations
   - Has at least a basic README and documentation
   - Has meaningful commits and activity (at least 5 stars or active development)

2. **For existing projects:** Fix typos, improve descriptions, update star counts, or suggest category changes

3. **Format:** Follow the markdown table format above with `[Project Name](URL) | ⭐ Stars | Language | Description`

## How to Contribute

1. Fork the repository
2. Add your changes
3. Submit a pull request with a clear description
