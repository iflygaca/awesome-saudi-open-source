## 🤝 Contribution Guidelines

Want to add your project or suggest improvements?

1. **Eligibility Criteria:**
   - Open-source license (MIT, Apache 2.0, GPL, or similar)
   - Created or maintained primarily by Saudi developers, teams, or organizations
   - Active repository with meaningful commits and clear documentation
2. **Format:** Submit your project following the table schema:
   ```markdown
   | [Owner/Repository](https://github.com/...) | ⭐ Stars | Language | Brief description highlighting Saudi context |
   ```
3. **Submit a PR:** Fork this repo, add your entry under the most fitting category, and open a Pull Request!
